# 分批疑義與校正清單

依使用者指示：單條怪異記入清單、繼續施工；每批結束一次提出，確認後才併入最終版本。
下列項目皆已在資料中處理（不更動 `error_usage`、例句、日文），但需使用者確認判斷。

## 全站（資料基準）

- **D1**：契約寫 89 個 `error_usage`／5,701 可用形／17,103 例句；實測為 **191／5,599／16,797**。來源是歷史 audit 快照，後續修訂新增錯誤形並刪除其例句。以現況 `vol/` 為準。
- **D2**：1 則 error note 用「錯誤用法」，其餘 190 則用「錯誤詞語」；已統一 L23#9 用語。
- **D3**：89 個動詞的 `potential-form.vol === passive-form.vol`（一段動詞同形）；已依各形例句／note 區分可能與受身，未更動 `vol`。
- **D4**：`passive-form` 混有直接被動、迷惑受身、尊敬語、事件／狀態四種；已分類，未更動 `vol` 或 `error_usage`。
- **D5**：`volitional-form` 有 25 個讓步構文（就算…也），不是「～吧」；已寫讓步語義。
- **D6**：3 個字典形中文本身已是變化後詞組（違う／違う／なくなる）；已逐形手寫，不再機械套模板。
- **D7**：狀態／認知動詞（見える、聞こえる、要る、足りる、できる、出来る 等）否定與可能不能套 `不X`／`能X`；已逐形手寫。
- **D8**：10 則 note 明說「不是『X』」；逐條確認新 `chinese` 不含 X，無矛盾。
- **D9**：89 個 form-specific「日常少用」note 曾搭配完全正常的中文；已在該形中文加「（此形日常少用）」。整個詞彙層級的 note（造る 15 形）不加。
- **D10**：例句中文／日文、句子 note、vol、group、japanese、sentence、error_usage 全部零變動；僅 `chinese` 5,420 處、note 1 處。
- **D11**：32 個無意志動詞的 `volitional-form` 例句其實是「快要／正要／即將…」，不是「～吧；打算…」（例如 壊れよう、亡くなろう、降ろう）；已改成即將語義，明確標示「不是『～吧』」。另有 1 個 `知る` 的使役 `知らせる` 是「通知／告訴」，不是「讓…得知」，已手寫。
