# 基準範例：第 2 課「違う」15 形

依 `rewrite-rules.md` §3，逐形對照 `vol/lesson_2.json` 自己的例句中文改寫。此動詞是狀態動詞（「不同／不對」），不是動作動詞，因此否定、可能、命令、受身、使役不能套用一般動作動詞的公式。

## 這個範例確立的規則

1. 否定形必須把「不／沒有」放進中文，不可再顯示肯定詞義。
2. 過去形必須表達「當時／之前／了／曾經」，不可與非過去同義。
3. `te-form` 必須寫出接續或因果，不可只給單詞詞義。
4. `volitional-form` 先判斷是提議／決心還是讓步構文；讓步句不可寫「～吧」。
5. `error_usage` 一律統一標示，不編造譯義。
6. `passive-form`／`causative-form` 要看動詞是動作還是狀態；狀態動詞的使役是「使…變得…」。
7. 禮貌／普通之差別在中文無法用動詞變化表達時，用簡短語體標示，但不把語體當成新詞義。

## `note` 處理

此動詞的 3 則 `error_usage` note 與 2 則一般 note（volitional／causative 的用法說明）都正確、沒有誤導初學者之處，保持原樣。第 2 批之後才逐課檢查是否需要校正。
