## 4. 為什麼這 89 個形被標 `error_usage`

三類，全部保留字面供「轉詞練習」：

1. **資料自己已標「是錯的／這是另一個動詞」**：例如
   `わかる→わかれる`、`できる→できられる`、`開く→開ける`、`つく→つける`、
   `合う→合わせる`、`減る→減らせる`、`乾く→乾かせる`、`叶う→叶える`。
2. **語法上不存在的形**（無意志動詞硬造可能形、命令形、受身形、使役形）：例如
   `降る→降れる`、`要る→要れる`、`咲く→咲ける`、`亡くなる→亡くなれる`、
   `増える→増えられる`、`なくなる→なくなれる`。
3. **受身形其實是尊敬語或另一個詞**：例如
   `ある→あられる`、`なる→なられる`、`残る→残られる`、`くれる→くれられる`、
   `困る→困られる`。

`note` 範例：

```
"note": "錯誤詞語，僅供轉詞練習：「わかれる」是錯的：「わかる」本身已表示可能（「分かれる」是另一個動詞）",
"error_usage": true,
"sentence": []
```

### 特別處理：審查員說「note 本身寫錯」的 16 個形

`曲がれる`、`知れる`、`役に立てる`、`止まれる`、`間違えられる`、`残れる`、
`変われる`、`過ぎられる`、`慣れられる`、`倒れられる`、`びっくりできる`、
`計れる`、`合える`、`酔える`、`量れる`、`向かえる` —— 這些其實是**正確可用**的可能形，
所以**沒有**被標 `error_usage`，造句保留，`note` 改成「字典有但是不常用；…」並說明用法／易混之處。

`着ける`（着く 可能形）、`被れる`（かぶる 可能形）也同理保留，並加註與他動詞同形易混。
