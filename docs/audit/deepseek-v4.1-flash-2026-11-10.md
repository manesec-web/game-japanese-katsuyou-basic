### 3.2 該形不是這個動詞能用的形（109 形改為 `error_usage`）

典型分三類：

**(a) 撞詞：字串其實是另一個動詞的形**

| 課 | 動詞・形 | 字串 | 說明 |
|---|---|---|---|
| 9 | わかる・命令形 | わかれ | 是 分かれる／別れる 的命令形；わかる 是狀態動詞，不能命令 |
| 2／28 | 違う・命令形 | 違え | 是 違える（＝弄錯、變更）的命令形 |
| 24 | くれる・命令形 | くれろ | 不成立；くれる 的命令形是「くれ」 |
| 29 | つく・受身形 | つかれる | 會讀成 疲れる／憑かれる；つく 沒有這種被動 |
| 29 | 付く・受身形 | 付かれる | 自動詞不能接動作主 |
| 26 | 片付く・受身形 | 片付かれる | 被動要用他動詞 片付ける 的 片付けられる |
| 34 | 気が付く・命令形 | 気が付け | 「気を付け（気を付ける）」是同音的另一個詞 |
| 21 | 足りる・命令形 | 足りろ | 無意志動詞，沒有可用的命令形 |

**(b) 受身形欄位被填成尊敬語（〜される／〜られる）**

例：`受ける` 受身形「受けられる」（校長先生は…受けられる）、`参加する`「参加される」、
`卒業する`「卒業される」、`出発する`「出発される」、`勤める`「勤められる」、
`過ごす`「過ごされる」、`安心する`「安心される」、`びっくりする`「びっくりされる」、
`がっかりする`「がっかりされる」、`泳ぐ`・`出る`・`結婚する`・`食事する`・`散歩する`
等。這些句子示範的是「尊敬」而不是「被動」，因此標為錯誤並刪例句。

**(c) 自動詞的使役形被既有他動詞取代（32 形）**

| 43 | 下がらせる | 下げる |
| 43 | 切れさせる | 切る |
| 43 | とれさせる | 取る |
| 43 | なくならせる | なくす |
| 44 | 濡れさせる | 濡らす |
| 50 | 叶わせる | 叶える |
| 39 | 焼けさせる | 焼く |
| 38 | 亡くならせる | 亡くす／死なせる |
| 32 | 直らせる／治らせる／続かせる | 直す／治す／続ける |
| 29 | 閉まらせる・開かせる(あく)・つかせる・すかせる・付かせる・止まらせる・掛からせる | 閉める・開ける・つける・空かす・付ける・止める・掛ける |
| 26 | 燃えさせる | 燃やす |

`見えさせる`（大きく見えさせる）、`聞こえさせる`（遠くまで聞こえさせる）、

### 3.4 解除誤標（1 形）

`L44 滑る・可能形「滑れる」`：原本標為錯誤（理由「無意志動詞」），但滑雪義的「滑る」
是有意志動作，雪場常用「雪が少なくて滑れない」「初心者でも滑れるコース」。因此解除
`error_usage`、移除舊註記、補 3 句自然例句。

### 3.5 不常用詞加註（規則 2）

對「字典有、但日常有更常用寫法」的動詞，套用到該動詞所有非錯誤形：

| 動詞 | 註記 |
|---|---|
| 造る | 字典有但是不常用：一般寫「作る」；「造る」多用於造船、造酒等大規模製造 |
| 遭う | 字典有但是不常用：日常多用「会う」；「遭う」多用於事故、災難等不好的事 |
| 計る | 字典有但是不常用：測量通常寫「測る」；「計る」多用於計算時間、數量 |

另外把 3 則「字典有但是不常用；」（分號）統一成「：」，維持格式一致。

## 四、判定政策（保留 vs 標錯的界線）

1. **真實可用、但少見** → 保留 3–5 句例句，加 `字典有但是不常用：…`。
2. **不是這個動詞可用的形**（撞詞、只有尊敬語讀法、自動詞硬造受身／使役、
   無意志動詞的可能／命令）→ `error_usage: true`、
   `note: 錯誤詞語，僅供轉詞練習：…`、`sentence: []`。
3. **同字串在可能形與受身形**：若可能形是自然日語（出られる、受けられる、勤められる、
   お茶をたてられる），保留可能形例句；受身形若只是尊敬語，標錯誤。兩欄判定不同是
   刻意的，不算不一致。
4. **對無生物發出的引用式命令**（「割れろ！」「咲け」）→ 語法成立但少用，保留為
   不常用；不標錯誤。
5. **自然的被害受身**（部下に 遅れられる、空き巣に 入られる、客に 泊まられる）→
   保留或改寫成自然的被害受身，不誤標。
